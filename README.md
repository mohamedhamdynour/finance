# محفظتي — Portfolio Pro

نظام شخصي لإدارة المحفظة المالية يعمل بالكامل من المتصفح، متصل مباشرةً بقاعدة بياناتك على Supabase.

---

## الميزات

### المالية
- **الحسابات البنكية**: تتبع أرصدة متعددة بعملات مختلفة
- **الأسهم والصناديق**: حيازات + أرباح/خسائر محققة وغير محققة
- **المعادن الثمينة**: ذهب/فضة بالوزن والسعر مع تصنيع وكاش باك
- **الشهادات الادخارية**: جدول دفعات + استرداد تلقائي عند الاستحقاق
- **الديون والأقساط**: تتبع دفعات + تنبيهات استحقاق
- **العمليات المتكررة**: تطبيق تلقائي + كشف أنماط تلقائي
- **الأهداف المالية**: تتبع التقدم + توقعات الوصول

### التحليل
- **المخاطر**: HHI، Sharpe، VaR، Max Drawdown، درجة التنويع
- **التوقعات**: منحنى الرصيد المستقبلي + وقت الوصول للأهداف
- **المقارنات**: MoM، QoQ، YoY + مقارنة الفئات
- **إعادة التوازن**: مقارنة بالتوزيع المستهدف + حاسبة توزيع مبلغ جديد
- **الضرائب**: ضريبة أرباح رأسمالية، توزيعات، عوائد شهادات

### الأدوات
- **الزكاة**: حساب شرعي مع الحول الهجري
- **تصدير Excel**: 13 ورقة بكل البيانات
- **تصدير PDF**: تقارير احترافية بمقاس A4
- **استيراد CSV**: من كشوف البنوك مع كشف تكرار وتصنيف تلقائي
- **OCR**: استخراج مبالغ وتواريخ من صور الفواتير
- **المرفقات**: تخزين مستندات مع signed URLs
- **الإشعارات**: Web Push (اختياري، يحتاج VAPID)

### الأداء
- **IndexedDB Cache**: تحميل فوري عند إعادة الفتح
- **Service Worker**: عمل كامل بدون إنترنت (PWA)
- **Lazy Load Chart.js**: توفير 200KB في أول تحميل
- **إعادة محاولة تلقائية**: عند تعثر الشبكة
- **مؤشر حالة الشبكة**: يتغير تلقائياً

### الأمان
- **Multi-user**: كل مستخدم له قاعدة بيانات منفصلة (RLS)
- **Soft Delete**: كل حذف قابل للاسترجاع
- **Audit Log**: سجل كامل لكل التغييرات
- **XSS Protection**: تهريب تلقائي لكل مدخلات المستخدم
- **Atomic Transactions**: RPC للعمليات المركبة
